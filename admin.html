The Three Pillars of Quality (M1)

Comment on these to suggest improvements for your Babbage Creative manager.

Usability

How easy is it for the player? Are there on-screen instructions? Is the score visible?

"Improvement: Add a 'Press Start' screen to increase usability for new players."

Maintainability

How easy is it for another programmer to edit? Uses comments and clear variable names.

"Improvement: Move procedural code into classes (OOP) to organize sprite logic."

Efficiency

Does it run smoothly? Are you checking for collisions only when necessary?

"Improvement: Optimize memory by deleting bullets once they leave the screen."

Analysis: Python vs Alternatives

To achieve the Distinction (2A.D1), you must evaluate your tools.

Strength of Python/Pygame

Python’s high-level syntax allows for faster development compared to languages like Visual Basic for graphics. Pygame provides specific Modules for sprite handling and sound, reducing the amount of raw code required to start.

Weakness of Current Approach

The current Procedural Code structure is a weakness. As the "Shmup" game expands with more enemy types, the code will become "spaghetti code." An Object-Oriented (OOP) approach would be a significant improvement for scalability.
